# 足球预测决策框架

## 每日三时段分析流程

```
09:00  早盘分析 → 拉赔率 + 伤停侦察 + 七维分析存档
10:00  复盘昨日 → 对照赛果, 四维归因, 更新ELO
18:00  午盘分析 → 最新赔率重跑七维分析存档
21:00  终盘预测 → 完整A-I报告 (22:00开球英超提前1小时出炉)
周一06:00 每周重训 → 刷新新赛季CSV + 重训 + 回测
```

---

## 决策逻辑链 (完整版)

每场预测必须标注以下因素中有数据的全部:

```
推 [选项] @ [赔率] | 信心 [高/中/低]

═══ 定量层 ═══
├─ ELO差: [+X] → 进攻力[A] / 防守力[D]
├─ 联赛画像: [Y联赛] → 主场ELO+[Z], 场均[G]球, 平局率[D]%
├─ 泊松λ: 主[λh] / 客[λa], 预期总球[T]
├─ 蒙特卡洛: 主胜[P%] / 平[Q%] / 客[R%]
├─ 市场隐含(Shin): 主[Pm%] / 平[Qm%] / 客[Rm%], margin[M]%
├─ 贝叶斯后验: 主[Pb%] / 平[Qb%] / 客[Rb%], 模型权重[W]%, N=[n]/M=[m]
├─ 蒸汽移动: [有/无], 方向, 幅度[X]%, 时段[早→午/午→晚]

═══ 赛前情境层 ═══
├─ 赛程密度: [N]天[N]场, 对手[已休息N天]
├─ 旅途消耗: [距离km], [是否有]时差
├─ 阵容完整: 核心缺阵[有/无], 伤停[N]人
├─ 场地因素: [天然草/人工草], [海拔m], [预计天气]
├─ 杯赛阶段: [资格赛/小组/淘汰赛], [首回合/次回合], 总比分[S]
├─ 战意评估: [必须赢/保平即可/无压力], 奖金 stakes [€]

═══ 市场质量层 ═══
├─ 赔率离散度: [X]%, [高共识/分歧/严重分歧]
├─ 博彩公司数: [N]家, 流动性[充足/一般/偏低]
├─ Pinnacle偏差: [主胜/平/客]偏离市场均值[X]%
├─ 亚盘vs欧赔: [一致/背离], 若背离→亚盘信号优先
├─ 大小球盘: [初→临], [升盘/降盘/不变]

═══ 历史校验层 ═══
├─ 交锋模式: [近N场] 主[W]-[D]-[L]客, 场均[G]球
├─ 同类比赛: 同联赛画像近[N]场,[ELO差>X]的胜率[Y]%
└─ 裁判风格: [场均黄牌/红牌/点球] (如有)

═══ 综合判断 ═══
├─ 模型方向: [主/平/客], 置信度[X]%
├─ 市场方向: [主/平/客], 置信度[X]%
├─ 一致性: [一致/分歧], 若分歧→分析原因
├─ 最终推荐: [选项] @ [赔率]
└─ 一句话: [核心逻辑, ≤30字]
```

## 因素权重矩阵

### 定量层 (自动计算, 权重固定)

| 权重 | 信号 | 触发条件 | 验证准确率 |
|------|------|----------|-----------|
| 1.5x | 蒸汽移动 | 赔率骤降>8% | **100%** (1/1) |
| 1.3x | 联赛画像 | 自适应参数替代通用 | 已验证提升命中率 |
| 1.2x | 亚盘vs欧赔背离 | AH方向≠1X2方向 | 斯巴达案例 ✅ |
| 1.0x | ELO差 > 60 | 实力差距显著 | 基线 |
| 0.9x | 交锋模式 | 近5场有规律性优势 | — |
| 0.8x | 伤缺信息 | 需官方来源确认 | NEC案例打脸→降权 |

| 权重 | 信号 | 适用 |
