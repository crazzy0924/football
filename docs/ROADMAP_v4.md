# v4.0 升级路线图
> 2026-08-14 · 依据基线报告（docs/BASELINE_2026-08.md）制定 · 按 ROI 排序

## Phase 1 · 冷启动治理（最高优先级，预期提升最大）
**问题**：25/57 场（44%）为冷启动；冷启动日准确率 25-30% vs 正常日 54%。
**动作**：
1. 冷启动场次自动降级：预测报告标注「无信号」，不产生投注信号（纪律已要求，需代码强制执行）
2. 冷启动先验升级：由"全联赛均值"改为"同联赛同级球队聚类均值"（按 ELO 区间分桶）
3. 训练库扩充：并入 openfootball 全库（h2h.py 提到本地 3 万场），压缩冷启动面
4. 队名规范化表扩充（中日韩/小联赛别名映射）
**验收**：冷启动占比 <30%；冷启动场次零投注信号；整体 Brier 下降 ≥0.005

## Phase 2 · 概率质量校准
**问题**：OU25 无技能（0.2562 vs 基线 0.24）；1X2 平局被系统性低估。
**动作**：
1. OU25 market-aware 校准：用大小球盘口赔率反推 λ，替代纯模型 λ（冷启动退化即源于此）
2. 平局校准增强：按联赛分桶的 draw_factor 动态化（当前为静态文件）
3. 概率校准（Platt/Isotonic）：对 1X2 输出做事后校准，改善 Brier
**验收**：OU25 过维度门禁（Brier < 0.24）；1X2 Brier < 0.2243

## Phase 3 · LLM 分析层上线（API 已验证 ✅）
**现状**：pipeline/analyst.py 已写好；DEEPSEEK_API_KEY 实测有效（v4-pro/v4-flash 可用）；
deepseek-harness 0.2.0 在 PyPI 存在。
**动作**：
1. 安装依赖：pip install deepseek-harness>=0.2.0（环境恢复后）
2. 端到端跑通：python pipeline.py predict --matches-json ... --llm
3. 验证报告渲染：分析师注释出现在 HTML 报告，标注「分析师注释(LLM)」
4. 失败降级路径测试（DeepSeek 失败 → 预测正常运行）
**验收**：--llm 全链路无报错；报告含中文分析师注释；API 不可用时预测正常

## Phase 4 · 每日自动化
**动作**：
1. 一键脚本 daily_run.cmd：build_today_matches → predict --llm → （次日）review
2. Windows 计划任务（每日 09:00 预测 / 21:00 复盘）或桌面启动器联动
3. 每日中文简报：合并预测 + 复盘 + 维度台账状态
**验收**：连续 3 天无人值守跑通；简报自动推送/落盘

## Phase 5 · 真实投注 P&L 账本
**动作**：
1. 新增 pnl_ledger.json：记录每笔下注（日期/场次/维度/方向/赔率/金额/结果）
2. review 命令自动结算：Brier + ROI + Kelly 实际执行情况
3. 与 dimension_ledger 打通：只有过门禁维度的信号才允许记账
**验收**：账本与复盘报告自动同步；ROI 按维度可查
