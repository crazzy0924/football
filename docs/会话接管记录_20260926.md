- 这个报错是**非终止错误**，`$ErrorActionPreference='Stop'` 拦不住 → 脚本继续往下跑，末尾 `exit 0`
  → **任务结果码 0（看起来成功），实际什么都没排**；
- 于是 9/28 那次一次性任务跑完后没续上，9/29 没有终盘任务 → E 盘看到「slate 0 场 / 赔率时点不变」→ 一直跳过。
