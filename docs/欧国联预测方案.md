## 0. 一句话

国家队是**另一套物理隔离的子系统**。欧国联只是它目前唯一启用的赛事。
它**不进** `config.PREDICT_LEAGUES`，也不碰 `pipeline.py` / `models/dixon_coles.py` 的有状态类。


## 5. 模型

Dixon-Coles，log 线性参数化:

```
lam_h = exp(mu + att[h] - dfn[a] + ha[comp] * (0 if neutral else 1))
lam_a = exp(mu + att[a] - dfn[h])
```

与俱乐部版的**三个关键差异**:

1. **支持中立场** — 中立场时主场优势项直接归零。俱乐部版没有这个字段。
2. **主场优势按赛事类型分组** — 友谊 / 欧国联 / 预选赛 / 决赛圈，而不是"按联赛"。
   实测: 友谊 x1.24 / 欧国联 x1.25 / 预选赛 x1.27 / 决赛圈 x1.36（决赛圈主场优势明显更大，合理）。
3. **友谊赛降权 0.65** — 换人多、试验阵容，比分不代表真实实力。

其他: 时间衰减权重做了**均值归一化**（否则衰减强度会和岭正则强度纠缠，网格搜索出来的参数无法解释 —— 这条纪律沿用俱乐部的）；
解析梯度手写（注意 `dfn` 的负号，见第 9 节踩坑）。

## 6. 超参 (只在**目标口径**上调)

**教训**: 一开始把超参调在"全部国际比赛"上，选出半衰期 1095 天。
但那个总体被大量水平稳定的非欧球队主导，而我们要预测的是**欧足联内部正式比赛**。
换成目标口径重调后:

| 半衰期 | 目标口径验证 Brier |
|---|---|
| 180 天 | 0.4630 |
| 365 天 | 0.4445 |
| 547 天 | 0.4410 |
| **730 天** | **0.4405** ← 选定 |
| 1095 天 | 0.4415 |

最终: `alpha_team=0.2`（岭正则）, `half_life_days=730`（2年）。
调参窗 = 2024-09-24~2025-09-24，**与最终留出窗不重叠**。

## 7. 融合规则 —— 为什么不用俱乐部那套贝叶斯

`models/bayesian.py:bayesian_fusion_predict` 的市场证据强度是**由赔率抽水驱动**的:
`margin_factor = 0.02 / margin`，抽水越大越不信市场。
俱乐部链路喂的是 Pinnacle（2–3%），所以这条成立。

但国家队侧唯一可得的是**体彩竞彩，抽水约 13%** → `margin_factor = 0.15` → 市场证据强度 M 只有 8，
而模型先验 N=20 → **模型权重 71%**。

那不是"市场不确定"，那只是**价格加成**（去水后的概率依然有信息量）。
直接套用等于让一个**从未与市场做过配对检验**的模型去否决市场 —— 这是纪律问题，不是调参问题。

所以改用**对数意见池**:

```
p_i ∝ p_model_i ** w  *  p_market_i ** (1 - w)      w = 0.10 (市场绝对主导)
```

`w` 显式写死、可审计、不随抽水漂移。**不许调高**（理由见第 8.4 节: 样本永远不够）。

### 7.1 方案 A 落地 (2026-09-24 用户拍板)

第 8 节的回测改变了这个子系统的**定位**: 目标口径上技能无法证明 → **模型只做诊断, 不做预测**。

| 机制 | 位置 | 说明 |
|---|---|---|
| `w = 0.10` | `run_nl.py: NL_MODEL_CONFIDENCE` | 从 0.20 降下来。市场绝对主导 |
| **分歧预警** | `run_nl.py: DIVERGENCE_ALERT = 8.0` | 模型与市场任一项差 ≥ 8 个点就打 ⚠。**这是模型唯一的用途**: 提示"市场可能看漏了什么"或"我们可能算错了"。**不是投注信号** |
| 赔率存档 | `data/national/odds_log.jsonl` | 每轮追加。jsonl 便于按场次聚合看赔率变动 |
| 语料刷新 | `national/refresh_corpus.py` | `--refresh` 触发。上游有 1-2 天延迟, 卡住时用 `results_local.csv` 补录 |

## 8. 验证结果

### 8.1 ⚠️ 先看这一条: 在我们真正的目标口径上, 技能**无法被证明**

> 目标口径 = 双方都是 League A 16 强。这正是我们今晚要预测的那类比赛。
>
> **DC 相对「无技能基准」(永远输出 1/3,1/3,1/3) 只改善 1.9%。**
> 对 Elo 的配对检验 t = −1.19, **不显著**; 对固定频率基准 t = −1.43, **也不显著**。
> 换句话说: **在这类比赛上, 我们拿不出"模型比瞎猜强"的统计证据。**

### 8.2 欧国联专项滚动回测

**为什么补做** (2026-09-24 用户指出): 之前一直用"欧足联内部+正式比赛"当**代理口径**,
而欧国联自己有 658 场历史 (2018/19 起)。应该直接在那个总体里验 —— 用户说得对。

方法: 18 个比赛窗, 每窗只用该窗之前的比赛训练 (滚动), 模拟真实生产。

| 口径 | n | DC | Elo | 基准 | 无技能 | DC−Elo | **相对无技能改善** |
|---|---|---|---|---|---|---|---|
| 全部欧国联 | 658 | 0.56812 | 0.58320 | 0.65386 | 0.66667 | t=−2.23 **显著** | +14.8% |
| **双方均为 League A** | **102** | **0.65499** | 0.67809 | 0.68063 | 0.66667 | t=−1.30 不显著 | **+1.9%** |

**模型的真本事全在"强弱分明"的比赛里。** League A 强强对话这个子集上, 它几乎没技能。

三个具体病灶 (n=102):

| 病灶 | 实际 | 模型 | 差 |
|---|---|---|---|
| 过度自信 (最高概率 0.50-0.60 桶) | 命中 41.7% | 说 53.9% | **−12.2 个点** |
| 平局漏报 | 平局率 **29.4%** | 平均只给 26.7% | −2.7 个点; **102 场里只把平局选为最高概率 1 次** |
| 高估主队 | 主胜 37.3% | 给 42.8% | +5.5 个点 |

注: League A 的平局率 (29.4%) **明显高于其他欧国联场次** (24.3%) —— 强强对话更容易平。

**校准能修吗? (前半段 51 场拟合, 后半段 51 场验证, 严禁拿全部 102 场调参)**

| 方案 | 验证段 Brier | 配对 t |
|---|---|---|
| 原始 DC | 0.64803 | — |
| 平局乘子 m=1.15 | 0.64588 | −0.38 不显著 |
| 向基准频率收缩 lam=0.50 | 0.64447 | −0.21 不显著 |
| 恒定基准频率 (无技能) | 0.66436 | +0.46 不显著 |

→ **两个修法都不显著。** 而且原始 DC 与"恒定频率无技能"的差**也不显著**。

### 8.3 扩到「16 强之间的一切对话」(不限欧国联)

| 口径 | n | DC | Elo | 相对无技能改善 | DC−Elo |
|---|---|---|---|---|---|
| 全部赛事 | 270 | 0.61140 | 0.62549 | **+8.3%** | t=−1.57 不显著 |
| 仅欧国联 | 102 | 0.65413 | 0.67444 | +1.9% | t=−1.19 不显著 |
| 仅决赛圈 (欧洲杯/世界杯) | 59 | 0.52954 | 0.51494 | **+20.6%** | t=+0.89 |
| 仅预选赛 | 61 | 0.60397 | 0.61228 | +9.4% | t=−0.53 不显著 |
| 仅友谊赛 | 48 | 0.63067 | 0.67412 | +5.4% | t=−2.15 **显著** |

两个值得留意的现象:
1. **欧国联是最难的一档** (仅 +1.9%)，**决赛圈是最容易的一档** (+20.6%)。
   合理解释: League A 是 16 支水平接近的队, 且欧国联轮换/试验阵容多 → 内在就难预测;
   决赛圈强弱跨度更大, 且各队全力出战。
2. **决赛圈 (欧洲杯/世界杯) 才是这套系统真正有价值的地方** —— 2028 欧洲杯有戏。

### 8.4 样本量现实 —— 这一条决定整个子系统的定位

实测 DC 的逐场 Brier 标准差 sd ≈ 0.169, 要在 t=2 下检出差异:

| 想检出的 Brier 差 | 需要场次 |
|---|---|
| 0.005 (很精细) | **14,928 场** |
| 0.010 | **3,732 场** |
| 0.020 (已经算很大的优势) | **933 场** |

现状: 16 强之间 2018 年至今共 **270 场**; 欧国联联赛阶段**每年只新增 48 场**。

> **结论: 在强强对话上, 靠我们自己的数据永远证明不了「模型 vs 市场」。**
> 俱乐部那套「配对检验说了算」的纪律, 在这个样本量下**不适用** ——
> 不是纪律错了, 是这条路根本走不到终点。
>
> 所以 `w` 永远只能是一个**基于先验的保守选择**, 不可能被数据"调优"出来。

### 8.5 代理口径的验证结果 (保留, 但**不能单独看**)

留出窗 2025-09-24 起, n=861:

| 口径 | n | Brier | 命中率 |
|---|---|---|---|
| 全部国际比赛 | 861 | 0.48804 | 62.1% |
| 仅正式比赛 | 563 | 0.48036 | 63.4% |
| 仅决赛圈 | 156 | 0.48506 | 67.9% |
| 仅欧足联内部 | 185 | 0.46985 | 64.3% |
| 欧足联内部 + 正式 | 124 | 0.45488 | 66.9% |

配对: DC − Elo = −0.03632 (se 0.00682, **t = −5.33 显著**); DC − 基准 t = −12.66。

⚠️ **这组数字看起来很好, 但它被"强弱分明的比赛"拉低了 Brier。**
第 8.2/8.3 节说明: 换成真正的目标口径, 优势就基本消失了。
**教训: 代理口径的漂亮数字不能代替目标口径的检验。**

### 8.6 仍然没证明的: vs 市场

> **本模型从未与市场赔率做过配对检验。**
> 我们没有任何历史国家队赔率 (Kaggle 那份需登录; GitHub raw 连接被重置; Apify 是收费的)。
> 所以"模型 vs 市场谁强"目前**完全未知** —— 叠加第 8.4 节的样本量现实, 它可能**永远是未知**。
> 这就是 `w` 被压在 0.20 的唯一原因。

## 9. 已知问题

### 9.1 挪威 vs 丹麦: 已查清「病灶在哪」, 但**没有修法** (2026-09-24 追查完毕)

**现象**

| 来源 | 挪威 | 平 | 丹麦 |
|---|---|---|---|
| 体彩 (去水) | 57.9% | 22.2% | 19.9% |
| 独立模型 [Goalence](https://goalence.com/league/uefa-nations-league/norway-vs-denmark-2026-09-24) | 53% | 23% | 24% |
| **我们 (DC)** | **43.6%** | 24.8% | 31.7% |

**病灶: 是 DC 一个模型的问题, 不是整个模型族的问题。**

| 球队 | DC 排名 | **我们自己的 Elo 排名** | 挪威−丹麦 强度差 |
|---|---|---|---|
| 挪威 | #16 (+2.206) | **#13 (1903.7)** | DC: **−0.040** |
| 丹麦 | #12 (+2.247) | **#28 (1797.1)** | Elo: **+106.6** |

**我们自己实现的 Elo 站市场那边, 只有 DC 不认。** 轨迹把原因指出来了:

| 截止 | 挪威−丹麦 DC 差 | 挪威−丹麦 Elo 差 |
|---|---|---|
| 2024-01 | −0.358 | −80.6 |
| 2025-07 | −0.178 | −1.7 |
| 2026-09 | **−0.040** | **+106.6** |

**Elo 早就追上了挪威的崛起, DC 几乎没动。** 根因不是半衰期长短, 而是
**DC 是纯"水平"模型、没有动量**; Elo 每场增量更新, 天然跟得上。

挪威自己近 12 场: 模型期望积分 17.8、实际 23 (**低估 5.2 分**)。
其中客场 4-1 意大利只给 28%、中立场 2-1 巴西只给 20%。

**但所有修法都试过了, 全部无效:**

| 修法 | 结果 |
|---|---|
| 缩短半衰期 (365天) | 挪威抬到 49.1%, 但整体验证更差 (0.4445 vs 0.4405) |
| 平局乘子 / 向基准收缩 | 目标口径上 t=−0.38 / −0.21, 均不显著 |
| **把 Elo 掺进 DC** | **目标口径上纯 DC 最优 (0.61155), 掺 Elo 更差** (0.5 时 t=+0.78) |
| **分歧时改用 Elo** | **更差**: 0.57471 vs 纯 DC 0.57168 (t=+1.08) |

最后一条尤其关键: **DC 与 Elo 分歧时, DC 并不输** (分歧场次 n=120: DC 0.65397/命中40.0%
vs Elo 0.67484/命中29.2%)。所以"Elo 在挪威上对了"只是巧合, 不是 Elo 更准。

复现: `python national/compare_dc_elo.py`

**结论与处理**

1. 模型与市场分歧时, **没有证据表明我们对** → 先验应该是"市场对"。这是 `w=0.10` 的依据之一。
2. 不为了对齐市场去手改参数 (那是拟合市场, 不是建模)。
3. **分歧预警的正确用法是去查场外信息** (伤停/征召名单/动机/场地), **不是改模型** ——
   因为所有基于赛果数据的修法都已证明无效。
4. 剩下两种解释我们**无法区分**: (a) DC 确实低估挪威; (b) 市场掌握了我们没有的信息。

### 9.2 用户点名要的四个特征: **全部判决完毕 (2026-09-24)**, 三个不能进模型

| 特征 | 判决 | 依据 |
|---|---|---|
| **休息天数 / 赛程密度** | **不加** | 见 9.2.1 —— 有判决性证据, 无可用信号 |
| **阵容连续性 (征召名单变化度)** | **受阻, 做不了** | 见 9.2.2 —— 四个数据源全部不通 |
| **战意分层** | **只做展示, 不进模型** | 见 9.2.3 —— 不可验证 |
| 主客场与非常规场地 | 部分支持 | 模型支持中立场; 但**未来赛程的场地信息仍无来源** (一律按主客场处理) |

#### 9.2.1 休息天数: 有证据的否决

用 Elo 差分控制球队强度后做回归 (净胜球 ~ Elo差分 + 休息差分):

| 检验 | n | 休息差分系数 | t |
|---|---|---|---|
| 全量 | 15,620 | −0.00077 球/天 | −3.68 |
| **窗口内 (双方休息 <14 天, 特征才有方差)** | **7,388** | **−0.00129** | **−0.07** |
| 总进球 ~ 双方休息天数 | 15,620 | 主 −0.0015 / 客 +0.0003 | −1.60 / +0.37 均不显著 |

系数 −0.0008 球/天 = 要 10 天休息优势才能挪动 0.008 个净胜球, **等于零**。
且**在特征真正有方差的区间 (MD2-MD4 那个场景) t=−0.07, 彻底无信号**。

场景直接对照:

| 场景 | n | 场均总进球 |
|---|---|---|
| 双方都赶 (≤5天, 即 MD2-MD4) | 6,185 | 2.760 |
| 双方都休够 (≥25天) | 5,683 | 2.691 |

差 +0.069, **t=+1.98 不显著**。

注: 描述性分桶里"主队更疲劳反而主胜率更高"是**选择效应** —— 那一桶的前十大主队是
墨西哥/卡塔尔/约旦/巴林/阿曼/日本/科威特/伊拉克/乌兹别克/新加坡, 全是赛程密集地区。
用 Elo 控制后系数就塌到 −0.0008, 与此吻合。

#### 9.2.2 阵容连续性: 四个源全部不通

| 数据源 | 状态 |
|---|---|
| SofaScore API | **全线 403** (Cloudflare 收紧) |
| api-football (RapidAPI) | **403 / 429**, 配额耗尽或 key 被封 |
| football-data.org | 通, 但 13 个赛事里国际赛事**只有 European Championship 和 FIFA World Cup, 没有欧国联** |
| TheSportsDB 免费档 | 每天只返回 3 场, 不可用 |

**结论: 在找到可及的"首发/征召名单"数据源之前, 这个特征做不了。**
不是"成本高", 是"没有入口"。

#### 9.2.3 战意分层: 做得出, 但验证不了 -> 只做展示

战意确实会影响比赛, 但**四个赛季里真正"有分化"的场次** (第 5/6 轮, 一方已定级)
加起来约 60 场, 而功效测算显示要检出 Brier 差 0.02 需要 **933 场**。
把它塞进模型 = 塞一个**无法证伪**的假设, 违反"先验证再加"的纪律。

所以实现为 **展示层** `national/standings.py`: 算小组积分榜 + 出线/降级形势标签,
在预测输出里显示一行。**模型权重完全不受影响。**

用途: **当分歧预警触发时, 给人一个去看形势的入口** —— 与 9.1 节结论 3 一致
(分歧时该查场外信息, 不是改模型)。

## 10. 下一步 —— 现在是一个需要拍板的岔路口

第 8 节的结论改变了定位: **目标口径上技能无法证明, 且样本量永远不够。**
所以原先写的"再攒 48 场就能定 `w`"是错的 —— 那条路走不到终点 (差 20 倍)。

摆在面前的是三个选项:

### 方案 A · 市场为主, 模型只做诊断 **【2026-09-24 用户已选定, 见第 7.1 节】**
- `w` 保持 0.20 或降到 0.10; 模型的定位改成**发现市场与模型的重大分歧** (如挪威那场),
  而不是提供独立概率。
- 成本最低, 且与我们已有的**全部**实测证据一致 (俱乐部侧: 下注信号是反向指标、edge 越大亏越狠)。

### 方案 B · 换战场, 主攻决赛圈
- 第 8.3 节显示"决赛圈"档相对无技能改善 **+20.6%**, 是唯一有像样信号的口径。
- 但决赛圈两年才一次, 样本更少, 只能当长期方向 (2028 欧洲杯)。

### 方案 C · 补特征后再评一次
- 接入休息天数 / 战意分层, 看能不能把 League A 那 +1.9% 抬起来。
- 风险: n=102 的统计功效太低 (第 8.4 节), 就算抬起来也多半是噪音。

### 无论选哪个, 这三件事都要做 (与选项无关)

1. **语料回灌**: 每轮结束后把新赛果并进 `data/national/results.csv`。
   否则 MD2 起"休息天数"和"近期状态"都是错的 —— 这是硬需求。
2. **赔率存档**: 每轮留下体彩赔率快照 (现在未必用得上, 但别的口径也许凑得够样本)。
3. **查挪威**: 模型唯一一次与市场的重大分歧, 值得搞清 (见第 9.1 节)。

## 11. 操作方式

```
# 出某个体彩比赛日的预测
python national/run_nl.py --date 2026-09-24

# 只算不写文件
python national/run_nl.py --date 2026-09-24 --dry-run

# 临时改模型权重 (默认 0.20, 不建议动)
python national/run_nl.py --date 2026-09-24 --mc 0.20

# 出预测 (推荐每轮都加 --refresh, 先重下上游语料)
python national/run_nl.py --date 2026-09-24 --refresh

# 只刷新语料, 看上游有没有新比赛
python national/refresh_corpus.py --check

# 留出验证 + 配对检验
python national/validate.py

# 欧国联专项滚动回测 / 强强对话回测
python national/backtest_nl.py
python national/backtest_elite.py

# DC vs Elo 对比 (两个已裁决问题, 别再重复试)
python national/compare_dc_elo.py

# 小组形势 (**纯展示, 不进模型**)
python national/standings.py
```

**注意**: `--date` 只决定输出文件名。预测范围是**全部未开赛的 League A 场次**（含次日挂出的）。

输出: `data/national/predictions_nl_<比赛日>.json` —— 含模型/市场/融合三套概率 + 分歧 + 波胆 + 元信息。

## 12. 踩坑记录

| 坑 | 症状 | 原因 |
|---|---|---|
| `dfn` 梯度漏负号 | 优化器 `nit=1` 一步冲边界，**四场预测完全相同** | ∂x_h/∂dfn_a = −1，我写成了 +1 |
| 超参调错总体 | 挪威被评低 5 个名次 | 在"全部国际比赛"上调，而不是目标口径 |
| 误用俱乐部贝叶斯 | 模型权重 71%，市场被架空 | 体彩 13% 抽水被当成"市场不可信" |
| SofaScore API 全线 403 | 拿不到国家队赛程/赔率 | Cloudflare 收紧，未解决 |
| **用代理口径代替目标口径** | 报出 0.45488 / 66.9% 的漂亮数字, 实际目标口径只改善 **1.9%** | 用"欧足联内部+正式"当代理, 而真正要预测的是"强强对话" |
| **没先算统计功效** | 以为"攒 48 场就能定 w" | 实测要 **933 场**才能检出 Brier 差 0.02, 48 场差了 20 倍 |
| 回测筛选条件用"当前"League A 名单 | 历史分级不同 (18/19 时塞尔维亚/挪威在 B 级) | 已知近似, 但仍是"我们真正要预测的那 16 队"的最接近代理 |
| **以为"换个更好的模型就能修"** | 追挪威时试了 4 种修法 (半衰期/校准/掺Elo/分歧时换Elo), **全部无效** | 没先问"这个修法可测吗"; 分歧时 DC 其实并不输给 Elo |
| 单文件里混了 JS 数组和 Python 行 | `run_code` 直接语法错误 ×2 | 拼脚本时最后一行误用了外层语法 |
| **用上一循环的残留变量** | 形势行显示成"土耳其/法国"(上一场) | 打印循环里用了 `h`/`a`, 那是构造循环的残留; 应改用 `l["home"]` |
| 形势标签边界写错 | 0 轮时全标"基本锁定第一" | `0 > -1 and 0 >= 0` 意外为真; 改用可证明条件 + 单元测试 |
