# 足球量化预测模型 · 迭代优化框架（修订版 v2）

> 修订日期: 2026-09-13
> 修订依据: 原框架第一章 1.2 与第六章建立在「模型可以稳定跑赢市场」这条假设上。本系统用
> 1752 场样本外回测与 38 场实盘结算把这条假设推翻了。本修订把世界观换成
> 「校准良好的概率就是目标，市场是必须先验」，并补上原框架缺的三块：
> 数据治理、小样本收缩、以及实测得到的分联赛参数。

---

## 第一章 总纲与核心原则

### 1.1 报告目的（改写）

原表述为「持续提升概率预测准确度与长期收益稳定性」。修订后：

**持续提升概率质量（校准度 + 区分度 + 稳定性），收益不进入目标函数。**

理由：本系统的收益类指标已经证明不可控——亚盘样本外收益率恒定在 −2.2%~−2.3%，
等于 Pinnacle 的抽水率。把收益写进目标函数，只会逼着模型去拟合噪声。

### 1.2 核心原则（改写）

1. **概率优先原则**（保留）
   输出概率分布而非确定性结论；核心是校准精准，不是猜中比赛。

2. **市场敬畏原则**（替换原「价值导向原则」）
   市场（Pinnacle）定价接近真实概率。模型与市场的分歧里，绝大部分是模型的噪声。
   **原「价值导向」表述作废**，理由见第六章。

3. **样本外有效原则**（保留并强化）
   所有迭代必须通过样本外滚动验证。**并且不能只比 Brier 绝对值**——组间方差远大于
   真实效应。判定必须用**配对检验**：在完全相同的比赛上比较两个模型的逐场得分差。
   本系统已把这条写进工具：逐场 Brier 差的 t 值要超过 2 才算成立。

4. **风险前置原则**（保留，但改为展示口径）
   本系统不输出投注信号，因此风控的对象不是资金，而是**结论的确定性**：
   数据缺失、方向冲突、盘口缺失时，宁可标注「结论不可用」，也不给一个打架的结论。

### 1.3 模型能力边界（改写）

| 项目 | 原框架 | 本系统实测 |
|---|---|---|
| 样本外 1X2 准确率 | 54%~62% | **51.1%**（1752 场）/ **53.7%**（255 场实盘） |
| 精确比分命中率 | 7%~13% | 进球总数最高档命中 **25%**，约为随机的 2 倍 |
| 长期收益 | 「持续捕捉市场低效」 | 亚盘 −2.2% 恒定，**模型等价于市场** |

**修订意见**：原框架把上限写到 62%，会诱导去上更复杂的模型——而那正是过拟合入口。
足球 1X2 的现实上界在 **52%~55%**，把它写实，比写高更有用。

## 第二章 理论基础

**保留**：泊松进球假设、Dixon-Coles 修正、ρ 耦合参数、时间衰减权重、ELO、xG。

**修正两点**：

1. **蒙特卡洛对本系统无用**。单场两队的比分联合分布，本系统是**精确枚举**比分矩阵
   得到的，蒙特卡洛只会引入采样噪声，不会更准。它只在「整届赛事夺冠概率」这类
   复合事件上才有价值，而那是另一类产品。

2. **新增：市场融合是第二条概率来源**。原框架把市场只当「比较基准」用来算 edge。
   本系统是把市场当作**贝叶斯先验**融进模型。这个差异决定了两件事的成败：
   它让我们的 Brier 尚可，同时也注定了「跑不赢市场」——因为我们的目标就是市场。

## 第三章 全链路架构

### 3.1 数据层（**原框架最大缺口，重点补写**）

原框架只写了「剔除腰斩、延期、判罚改分」。真实丢准确率的地方在下面三类，本系统全部踩过：

1. **赛事范围过滤**。结果源不带赛事过滤参数时，会混进全球范围的青年队、预备队、
   女足赛事。本系统曾一次性混入 **483 场青年/预备队**记录，污染了整个复盘口径。
   规则：数据源必须**服务端过滤**，本地再做一次兜底剔除。

2. **命名空间打通**。同一支球队存在三套名字：
   - 体彩给中文（勒芒）
   - SofaScore 给英文（Le Mans）
   - 赛果源给全称（Stade Rennais FC 1901）
   三套名字没打通时，表现为「这一场莫名没有盘口」「这场永远结算不了」。
   本系统的解法是维护一张**队名总表**（体彩中文 ↔ SofaScore 英文 ↔ 内部规范名），
   并且要求索引必须覆盖体彩中文名——否则中文进场就归不到英文规范名上。

3. **抓取失败必须报警，禁止静默降级**。本系统曾出现：盘口抓取连续两次失败，被异常
   捕获吞成一句警告，预测拿着**前一天的旧盘口**照常出报告。
   规则：抓取后比对目标文件的修改时间，本轮没写成功就大声报警并给出手工重跑命令。

### 3.2~3.6 其余各层

特征层、模型层按第四章、第五章执行；决策层见第六章；风控层改为
**不确定性披露层**；评估层见第七章。

## 第四章 特征工程迭代规范

### 4.1 特征分类
保留基础实力、状态趋势、情境修正三类。

### 4.2 预处理
保留时间衰减、标准化、分箱。**时间衰减已落地并分联赛定值**，见附录 B。

### 4.3 筛选（改写）

原框架的 IV 值检验、皮尔逊相关筛选（>0.7 保留其一），**对本系统不适用**：
本模型每队只有 2 个内生参数（进攻强度、防守强度），加上 ELO 与市场，特征维度极低，
不存在多重共线性问题。IV 筛选是给几百维特征工程准备的，照做等于自造工作量。

**改为**：新增特征必须通过**配对检验**——在完全相同的比赛上，逐场 Brier 差的
t 值超过 2，才允许纳入。

### 4.4 迭代流程
保留「假设 → 计算 → 单因子回测 → 全模型回测 → 样本外验证 → 入库」，
但把「样本外验证」的口径定义为配对检验，而非比较 Brier 绝对值。

## 第五章 概率计算与校准

### 5.1 Dixon-Coles 全流程
保留。ρ 修正公式（0-0、1-0、0-1、1-1 四个比分的修正）与业界标准一致。

### 5.2 概率校准
保留 Platt 缩放与保序回归的思路。**本系统已实现**：10 桶 + PAV 平滑的保序校准，
以及分联赛的平局校准因子，产物落在状态目录里。

**新增**：校准曲线要定期出报告，作为常规审计项，而不是只在调参时看一眼。

### 5.3 常见偏差与修正方向
保留：低比分平局低估（ρ 修正）、强队高估、杯赛不确定性。
**补充一条本系统实测的教训**：平局概率**总量上校准正确、逐场上没有区分度**。
把预测平局率分桶后，实际平局率并不随预测上升——排序是噪声。
因此「模型几乎不押平」不是缺陷，是理性结果；强行押平只会让准确率从 52.7% 掉到 45.6%。

## 第六章 价值决策与风控体系（**整章重写**）

### 6.1 原章节作废声明

原框架「价值投注判定 + 凯利公式 + 仓位风控」全部作废。实测证据：

| 证据 | 结果 |
|---|---|
| 样本外 1752 场（生产同款 MLE） | 1X2 −3.4~−4.8%；大小球 −0.3~−6.3%；**亚盘 −2.2~−2.3%（恒定等于抽水）** |
| edge 与结果的关系 | **edge 越大亏得越狠**：阈值 15% 时命中率 28.1%，收益率 −25.4% |
| 开赛以来实盘 38 场可结算 | 命中 13/38 = 34.2%；四分之一凯利收益率 **−24.7%** |

**机理**：模型与市场的分歧里绝大部分是模型噪声，不是市场漏掉的价值。
「模型算出 edge」的真实含义是**模型算错了，市场没算错**。

**并且**：原 6.4 的止损、连亏减仓救不了负期望。一个期望值为 −25% 的策略，
减仓只是让它更慢地亏。

### 6.2 替代方案：分歧只作诊断指标

保留 edge / 模型-市场分歧，但**只用于观察模型在哪里与市场不一致**，
作为模型改进的线索，不作为下注依据。纪律：

1. 禁止任何形式的下注建议——不输出凯利、不输出建议注额、不输出「看好方向」。
2. edge 越大越要警惕，**不是**越该下注（与原规矩完全相反）。
3. 复盘时若某场 edge 极大，**优先怀疑模型**。
4. 本系统定位为**分析展示平台**，不是下注系统。

### 6.3 不确定性披露层（替代原风控层）

- 数据缺失（无盘口、无赛果）→ 显式标注缺口，不猜。
- 方向与比分冲突 → 强制降级为「结论不可用」，不允许同时输出打架的结论。
- 冷启动球队（样本不足）→ 标注「非五大仅观察」。

## 第七章 回测评估与过拟合防范

### 7.1 指标体系
- **概率质量（核心）**：Brier、对数似然、校准误差。**这是唯一的验收维度。**
- 收益风险：最大回撤、夏普等。**降级为诊断项，不作验收**。
- 交易行为：本系统不适用。

### 7.2 回测方法（强化）
保留滚动回测、分层回测。**新增两条本系统的硬规则**：

1. **配对检验**。比较两个模型时，必须在同一批比赛上比逐场差值的均值与标准误，
   报告 t 值与置信区间。只看 Brier 绝对值会被组间方差淹没。
2. **以市场为参照线**。回测必须同时输出「同批比赛的市场去水概率 Brier」。
   本系统实测：模型 Brier 0.5924，市场 0.5728——市场始终优于模型约 0.02。
   不知道这条线，就会把「跑赢常数基准」误当成「跑赢市场」。

### 7.3 过拟合防范
保留简化模型、正则化、时间序列交叉验证、特征数量约束。
**补充本系统的小样本处理**（原框架缺失）：

薄样本赛事不能直接丢进全局拟合。本系统对欧冠这类薄样本（503 场 / 63 队，
约每队 16 次出场，40% 的队不足 10 场）采用**跨联赛收缩**：
权重 w = n / (n + 30)，把本队参数向同队在其他联赛的参数收缩。
实测 6 场样本的 Brier 从 0.1733 降到 0.1423，偏差从 +3.2pp 降到 −1.4pp。

## 第八章 自我迭代与漂移应对

### 8.1 滚动更新
本系统现状：每周一 06:00 刷新 CSV 语料 → 全量重训 → 回测 → 周复盘。
这比原框架的「月度重训」更密，直接沿用。

### 8.2 漂移检测（新增落地）

原框架的 PSI 思路正确，但**监控对象要改**：本模型特征维度极低，
不能照搬高维特征工程那套。本系统实现 pipeline/drift_monitor.py，盯三样：

1. **总进球分布**——直接决定大小球与双进球
2. **胜平负构成**——直接决定 1X2 先验（平局率尤其敏感）
3. **ELO 评级分布**——联赛整体实力结构与升降级换血

阈值沿用行业惯例：PSI < 0.10 稳定 / 0.10~0.25 轻微漂移 / > 0.25 显著漂移。

**并且必须加小样本闸门**：当前窗每联赛只有 18~41 场时，单场进球就能把 PSI 推到
0.48 以上，那是噪声不是漂移。本系统设为当前窗不足 60 场就不出判定，直接标
「样本不足」——避免狼来了。

### 8.3 参数优化
保留网格搜索 + 贝叶斯优化。**必须分联赛定值，禁止一套模板套所有联赛**。
实例见附录 B：时间衰减在 PL 上显著改善，在 FL1 上显著变差，在总体口径上互相抵消。

### 8.4 迭代闭环
保留原闭环，并在「样本外验证」节点插入配对检验。

## 第十章 分阶段落地执行路线图（验收标准重写）

| 阶段 | 目标 | 验收标准（修订后） |
|---|---|---|
| 一 · 基础能力 | 跑通概率输出链路 | 可输出单场胜平负概率，指标可计算 |
| 二 · 基准模型 | 升级到 Dixon-Coles | 样本外 Brier 较原始泊松下降 ≥5% |
| 三 · 优化校准 | 特征工程 + 概率校准 | **样本外 Brier 不劣于市场**；校准曲线贴合；相对常数基准显著提升。**收益项从验收中移除** |
| 四 · 自动迭代 | 监控 + 漂移 + 自动优化 | 漂移预警定期自动跑；参数**分联赛**定值；新的参数改动有配对检验支撑 |

原第三阶段验收写的是「样本外收益曲线正向，最大回撤≤15%」——**不可达**
（亚盘收益率恒定 −2.2%），必须删除，否则整个阶段永远无法通过。

## 附录 A · 本系统实测结论索引

1. **下注信号是反向指标**：样本外 1752 场与实盘 38 场一致，edge 越大亏越狠。
2. **模型等价于市场**：亚盘收益率恒定等于 Pinnacle 抽水。
3. **平局概率无横截面区分度**：分桶后排序是噪声；强行押平让准确率 52.7% → 45.6%。
4. **单日平局率高不是异常**：318 场全期平局率 27.0%，单日标准差 17.4%，
   50% 的日子在 23 天里出现过 3 次。
5. **跑赢常数 ≠ 跑赢市场**：模型 Brier 0.5924 优于常数基准，但仍劣于市场 0.5728。
